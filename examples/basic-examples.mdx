## Personalizer (frozen encoder)

Wrap any `encode(X) → Z`, personalize online, consume `BrainState`.

```python
from nimbus_bci import Personalizer, wrap

# Toy identity encoder — replace with partner / foundation encode(X) → Z
enc = wrap(lambda X: X, model_id="demo-encoder", embedding_dim=16)
adapter = Personalizer(
    encoder=enc,
    head="lda",
    classes=["left", "right"],
    preset="research",
)
adapter.fit(X_cal, y_cal)
states = adapter.predict(X_test)
print(states[0].intent, states[0].confidence, states[0].need_more_data)
```

Already have CSP / bandpower features? Use `Personalizer(encoder=None, head="lda"|...)` — same app surface. Full contract: [Personalizer](/personalizer/overview).

## Motor imagery

Motor imagery workflows usually use CSP or bandpower features from 8–30 Hz EEG — or embeddings from a frozen trunk.

<Tabs>
  <Tab title="Python">
```python
from nimbus_bci import Personalizer
from nimbus_bci.compat import extract_csp_features
from sklearn.model_selection import cross_val_score

# epochs: MNE Epochs object, already filtered and artifact-cleaned
X, csp = extract_csp_features(epochs, n_components=8)
y = epochs.events[:, 2]

adapter = Personalizer(
    encoder=None,
    head="lda",
    classes=["left", "right"],
    preset="research",
)
adapter.fit(X, y)
states = adapter.predict(X[:5])

# Research CV still uses the head
scores = cross_val_score(adapter.head, X, y, cv=5)
print(states[0].intent, f"CV accuracy: {scores.mean():.2%}")
```
  </Tab>
  <Tab title="Julia">
```julia
using NimbusSDK
using Statistics

NimbusSDK.install_core("your-api-key")

features = load_csp_features()  # (n_features, n_samples, n_trials)
labels = load_labels()          # 1-indexed labels

metadata = BCIMetadata(
    sampling_rate = 250.0,
    paradigm = :motor_imagery,
    feature_type = :csp,
    n_features = size(features, 1),
    n_classes = length(unique(labels)),
    chunk_size = nothing
)

data = BCIData(features, metadata, labels)
model = train_model(NimbusLDA, data; iterations=50)
results = predict_batch(model, data)

accuracy = mean(results.predictions .== labels)
println("Accuracy: $(round(accuracy * 100, digits=1))%")
```
  </Tab>
</Tabs>

Default head is LDA (`Personalizer(head="lda")`). Try `head="qda"` when class covariances differ substantially.

## P300 detection

P300 examples usually use ERP amplitude features from a post-stimulus time window.

<Tabs>
  <Tab title="Python">
```python
from nimbus_bci import Personalizer

# epochs: target/non-target MNE epochs
sfreq = epochs.info["sfreq"]
start = int(0.3 * sfreq)
stop = int(0.5 * sfreq)

X = epochs.get_data()[:, :, start:stop].mean(axis=2)
y = epochs.events[:, 2]

adapter = Personalizer(
    encoder=None,
    head="qda",
    classes=["nontarget", "target"],
    preset="research",
)
adapter.fit(X, y)
states = adapter.predict(X[:10])
print(states[0].intent, states[0].confidence)
```
  </Tab>
  <Tab title="Julia">
```julia
using NimbusSDK

features = load_erp_features()  # (n_channels, n_samples, n_trials)
labels = load_labels()

metadata = BCIMetadata(
    sampling_rate = 250.0,
    paradigm = :p300,
    feature_type = :erp_amplitude,
    n_features = size(features, 1),
    n_classes = length(unique(labels)),
    chunk_size = nothing
)

data = BCIData(features, metadata, labels)
model = train_model(NimbusQDA, data; iterations=50)
results = predict_batch(model, data)
```
  </Tab>
</Tabs>

## Streaming

Streaming uses short feature chunks and aggregates chunk predictions into a trial decision. Bridge to `BrainState` for apps.

<Tabs>
  <Tab title="Python">
```python
from nimbus_bci import (
    NimbusLDA,
    StreamingSession,
    brain_state_from_streaming_result,
)
from nimbus_bci.data import BCIMetadata

clf = NimbusLDA().fit(X_train, y_train)

metadata = BCIMetadata(
    sampling_rate=250.0,
    paradigm="motor_imagery",
    feature_type="csp",
    n_features=X_train.shape[1],
    n_classes=len(set(y_train)),
    chunk_size=250,
)

session = StreamingSession(clf.model_, metadata)

for chunk in feature_stream:
    session.process_chunk(chunk)

final = session.finalize_trial(method="weighted_vote")
state = brain_state_from_streaming_result(final, classes=["left", "right"])
print(state.intent, state.confidence, state.need_more_data)
session.reset()
```
  </Tab>
  <Tab title="Julia">
```julia
session = init_streaming(model, metadata)

for chunk in feature_stream
    result = process_chunk(session, chunk)
end

final = finalize_trial(session; method=:weighted_vote)
```
  </Tab>
</Tabs>

For frozen-encoder product apps, prefer [Personalizer](/personalizer/overview) (batch `predict` → `BrainState`) over a raw streaming session. API detail: [Python Streaming Inference](/python-sdk/streaming-inference), [Streaming inference configuration](/inference-configuration/streaming-inference).

## Calibration and normalization

Estimate normalization parameters from calibration or training data only, then reuse them for test and deployment data.

<Tabs>
  <Tab title="Python">
```python
from nimbus_bci import estimate_normalization_params, apply_normalization

norm = estimate_normalization_params(X_train, method="zscore")
X_train_norm = apply_normalization(X_train, norm)
X_test_norm = apply_normalization(X_test, norm)
```
  </Tab>
  <Tab title="Julia">
```julia
norm = estimate_normalization_params(train_features; method=:zscore)
train_norm = apply_normalization(train_features, norm)
test_norm = apply_normalization(test_features, norm)
```
  </Tab>
</Tabs>

See [Feature Normalization](/inference-configuration/feature-normalization) for cross-session details.

## Diagnostics

Run diagnostics when confidence is unexpectedly low or accuracy drops across sessions.

```julia
report = diagnose_preprocessing(bci_data)

if !isempty(report.errors)
    error("Preprocessing errors: $(report.errors)")
end

println("Quality score: $(round(report.quality_score * 100, digits=1))%")
```

For Python trial-level quality checks, see the [Python SDK API Reference](/python-sdk/api-reference#metrics) and [BrainState](/personalizer/brain-state) gates.

## Choosing a starting point

| Path | Use first when | Notes |
| --- | --- | --- |
| `Personalizer` + `wrap` | Frozen / foundation encoder | Product wedge → `BrainState` |
| `Personalizer(encoder=None)` | Classical CSP / bandpower / ERP features | Same app surface; pick `head=` |
| Standalone `NimbusLDA` / … | Research CV, sklearn pipelines | Heads power Personalizer under the hood |
| Julia `NimbusLDA` / `NimbusQDA` | Julia SDK workflows | No Personalizer yet |

| Head | Typical use |
| --- | --- |
| `lda` | Fast motor-imagery baseline |
| `qda` | Overlapping distributions (e.g. P300) |
| `softmax` | Nonlinear multinomial (Python extra) |
| STS / Probit | Long-session drift (Python) / Julia multinomial |

Full comparison: [Model Specification](/model-specification).
